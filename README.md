# WiFi LAN File Drop - দ্রুত পিসি ফাইল ট্রান্সফার

লোকাল ওয়াইফাই ও ল্যান নেটওয়ার্কে একাধিক পিসি ও ল্যাপটপের মাঝে উচ্চগতির ফাইল ট্রান্সফার সফটওয়্যার।

## 📁 প্রজেক্ট স্ট্রাকচার (Source Code)

* `src/` — React, Tailwind CSS ও WebRTC ফাইল ট্রান্সফার ইউজার ইন্টারফেস
* `electron/` — Electron ডেস্কটপ অ্যাপ্লিকেশনের মেইন ও প্রিলোড ফাইল
* `scripts/` — আইকন তৈরি এবং উইন্ডোজ বিল্ড স্ক্রিপ্ট
* `public/` — অ্যাপ্লিকেশনের আইকন ও স্ট্যাটিক এসেট
* `server.ts` — লোকাল সিগন্যালিং ও ডিরেক্ট আইপি কানেকশন সার্ভার
* `package.json` — প্রজেক্ট কনফিগারেশন ও ডিপেন্ডেন্সি তালিকা

---

## 🚀 উইন্ডোজ সফটওয়্যার (.EXE) তৈরি করার নিয়ম

1. **`BUILD-WINDOWS-EXE.bat`** ফাইলে ডাবল-ক্লিক করুন।
2. স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে:
   - ডিপেন্ডেন্সি ইনস্টল করবে (`npm install`)
   - ফ্রন্টএন্ড ও সার্ভার বান্ডল তৈরি করবে (`npm run build`)
   - উইন্ডোজ ডেস্কটপ সফটওয়্যার প্যাকেজ করে **`release`** ফোল্ডারে তৈরি করবে (`npx electron-builder --win`)
3. বিল্ড শেষ হলে স্বয়ংক্রিয়ভাবে **`release`** ফোল্ডার তৈরি হবে এবং ওপেন হবে।
